# vpsbox

VPS 初始化、系统优化与 sing-box 节点管理脚本。

当前版本：`v1.0.65`

## VPS 一键安装

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/TianPingXi/vpsbox/main/vpsbox.sh)
```

## 管理命令

安装完成后，可随时输入以下命令打开管理面板：

```bash
vpsbox
```

## 使用 IPv6 创建 VLESS Reality 节点

进入“节点管理 → 创建/重建 VLESS Reality 节点”，在节点连接地址处输入 VPS 的公网 IPv6，例如 `2001:db8::10`，也可输入带方括号的 `[2001:db8::10]`（此处仅为文档示例地址）。生成的分享链接会自动使用 `[IPv6]:端口` 格式。留空仍自动检测公网 IPv4；Reality 目标和 SNI 仍使用域名。

VPS 和客户端都需要可用的 IPv6 网络，云安全组和主机防火墙需要放行该节点的 TCP 端口。脚本会检查本机 IPv6 监听条件，并在创建后验证 IPv6 TCP 监听；这不能代替公网连通性验证。IPv6 已禁用或不可用时会取消创建，不会自动启用 IPv6。

更新脚本不会改写已有节点。需要把旧节点改成 IPv6 地址时，可主动重建；重建会重新生成凭据，请重新导入节点链接。

## sing-box 版本管理

sing-box 当前受管版本为 `1.14.4`。升级脚本不会自动替换已安装的内核；需要更新时进入“sing-box 管理 → 更新 sing-box”。该入口固定更新至受管版本，不跟随上游自动升级，也不将更高版本降级。

sing-box 管理菜单和一键检测会显示受管版本与上游最新稳定版，并标注查询时间。成功结果缓存 24 小时，查询失败短暂限频并明确标注旧缓存或无法确认；菜单中的“检查上游最新稳定版”可手动刷新。发现更高的上游版本只提示，不改变安装目标。

## 回国流量限制

进入“节点管理 → 回国流量限制”开启、关闭或手动更新规则。默认关闭，可以先设置再创建节点；开启后同时作用于已有和后续创建的受管 VLESS Reality、Shadowsocks 节点，节点凭据和分享链接保持原样。实际应用需要 sing-box `1.14.4` 或更高版本；旧内核请先从 sing-box 管理菜单更新。

限制依据 [Loyalsoldier CN SRS 规则集](https://github.com/Loyalsoldier/geoip/tree/release/srs) 判断代理请求的目标 IP，覆盖 IPv4、IPv6、TCP 和 UDP。域名先使用系统 DNS 解析，只要任一返回地址命中 CN 规则，整个请求就会被拒绝，包括同时返回 CN 与非 CN 地址的域名。其范围是节点转发的目标流量；国内客户端仍可连接节点，Reality 握手/fallback 和 VPS 自身进程流量不在这项路由策略内。IP 归属规则有更新延迟和误判可能，不能据此识别所有“中国网站”。

首次实际应用时下载并验证本地规则，后续由菜单手动更新，不设置定时下载。运行中的节点在策略变化时会重启，已有连接可能中断；原本停止的服务保持停止。下载或应用失败会回滚，并保留未完成恢复的事务材料。相同开关和相同规则不重复重启。存在自定义 DNS、路由或非受管入站的节点会拒绝自动启用，避免覆盖现有配置。

一键检测和限制菜单会显示策略状态、规则摘要及本地更新时间。规则缺失或损坏会报告异常；可以离线关闭限制，再更新规则后重新开启。删除最后一个节点会保留偏好和规则缓存，完整卸载节点才一并清理。
